# GDFC DEMONLIST 3.0

Статический сайт рейтинга Geometry Dash на HTML, CSS и vanilla JavaScript. Визуальная система использует айдентику GDFC, каталог рейтинга и тёмные строки уровней. Весь изменяемый текст, настройки, категории и записи находятся в JSON.

## Локальный запуск

Страницы используют `fetch()` для чтения JSON, поэтому их нужно открывать через локальный HTTP-сервер, а не через `file://`.

Для запуска двойным щелчком откройте `Запустить сайт.bat`. Он запускает сервер и открывает страницу в браузере. Окно сервера оставьте открытым, пока пользуетесь сайтом; чтобы остановить сервер, закройте это окно.

Либо запустите сервер вручную из корня проекта:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000`. Остановка сервера: `Ctrl+C`.

## Данные

- `data/config.json` — название, тексты, категории, настройки списка и подписи.
- `data/levels.json` — уровни и победители. Для уровня используются `creators` (массив создателей), `verifier` (ID игрока из `players.json`), `levelId`, `showcase` и список `victors`.
- Showcase может быть обычной ссылкой YouTube; миниатюра извлекается автоматически.
- Баллы за уровень рассчитываются на клиенте по его текущей позиции и отдельно в JSON не сохраняются.
- Поля уровня, кроме `id`, необязательны. Пустые значения не ломают страницы.

## Локальный редактор

Откройте `admin\Запустить редактор.bat`. Редактор откроется отдельным окном Windows, не требует localhost и не попадает в публикацию GitHub Pages.

- Уровень можно добавить через `+` в каталоге, затем заполнить позицию, ID, создателей, верифера и остальные поля.
- Поле `Showcase уровня` задаёт одно общее видео уровня.
- В разделе «Победители» у каждого игрока отдельно указывается дата 100% и ссылка на его прохождение.
- Кнопка «Сохранить локально» записывает `data/levels.json` и `data/players.json`.
- Кнопка «Отправить на GitHub» сохраняет данные, создаёт коммит только для этих двух JSON и отправляет его в `main`. Git использует сохранённый вход Git Credential Manager; токен в браузер не передаётся.
- «Редактировать JSON» открывает расширенный режим для прямого изменения структуры.

Если GitHub попросит войти, завершите вход в открывшемся браузере и нажмите «Отправить на GitHub» ещё раз. После push сайт обновится автоматически через GitHub Actions.

## GitHub Pages

Сайт не требует сборки. Workflow `.github/workflows/pages.yml` публикует корень ветки `main` через GitHub Pages. В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. Ссылки и загрузка JSON строятся относительно текущего URL, в том числе при размещении в подпапке репозитория.

Расчёт рейтинга покрыт тестами Node.js без дополнительных пакетов:

```powershell
node --test
```

Перед публикацией замените демонстрационные записи в `data/levels.json`. Публикация не производится автоматически из этой рабочей копии.
